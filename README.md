# Idler (working title)
Idle game made in low level rust.
## How to run
The latest release should have a "idler-windows.exe" and a "idler-linux". Find the appropriate one, and run it. The windows version should work on windows 11 and the linux version should work anywhere. Dynamically linked libraries may be missing in either case, but I don't really know which ones are needed, sorry.
## Controls
* LMB - click buttons
* RMB/MMB drag or WASD - move camera
* MMB scroll - zoom camera
* H - return camera to starting position
